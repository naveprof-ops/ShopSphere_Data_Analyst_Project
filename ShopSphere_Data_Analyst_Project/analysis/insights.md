# ShopSphere — Generated Business Insights

The following insights were calculated from the generated dataset rather than invented beforehand.

1. **Revenue concentration:** Electronics is the highest-revenue category, contributing ₹37,986,909 in gross order value among non-cancelled orders.
2. **Retention:** The repeat purchase rate is 89.8%, meaning a measurable share of active customers placed more than one non-cancelled order.
3. **Returns:** Overall return rate is 7.6%. Fashion has the highest category-level return rate at 14.8%.
4. **Cancellation:** Overall cancellation rate is 5.4%. The East region has the highest cancellation rate at 6.0%.
5. **Order economics:** Average order value is ₹9,313, which provides a baseline for evaluating promotions and customer segments.
6. **Estimated profitability:** Estimated gross contribution after product cost is ₹41,551,718; this excludes overhead, marketing spend, logistics cost and taxes.
7. **Business focus:** Categories with both meaningful revenue and elevated returns should be investigated at product and return-reason level before increasing promotional spend.
8. **Operational focus:** The region with the highest cancellation rate should be reviewed for payment failures, inventory availability, fulfillment delays and customer-service patterns.
