# Resume-ready project bullets

**ShopSphere — Customer Retention & Revenue Analytics | SQL, Power BI, DAX, Python**
- Analyzed 21,065 e-commerce transactions using SQL to evaluate revenue, customer retention, repeat-purchase behavior, returns, cancellations and product performance.
- Built an interactive Power BI-ready BI model with KPI measures for revenue, AOV, repeat-purchase rate, return rate, cancellation rate, profit and MoM growth.
- Applied customer/RFM analysis and category-level return analysis to identify high-value customers, retention opportunities and potential revenue leakage.
